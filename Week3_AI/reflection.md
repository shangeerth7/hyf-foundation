# Reflection

## 1. Three things I learned from AI

I learned how HTML, CSS, and JavaScript work together in a website. I learned how to connect a CSS file to HTML and use CSS to change the design of my website. I also learned how JavaScript can make a button interactive and change the background color when the button is clicked.

## 2. Where I tweaked or corrected Copilot suggestions

Copilot suggested adding `max-width: 100%` and `height: auto` to my image CSS to make the image more responsive on narrow screens. I reviewed the suggestion and understood that these properties would prevent the image from becoming wider than the available space and would keep its proportions. I added the suggested CSS to my project and tested the website to make sure it worked correctly.

## 3. Copilot as a code generator and as a learning partner

Copilot can generate code very quickly, but getting code is not the same as understanding it. When Copilot works as a learning partner, it can help me understand what the code does and why each part is used. This helped me understand the connection between HTML, CSS, and JavaScript instead of only copying code.

## 4. Three risks of relying too much on AI

One risk is that I may copy code without understanding how it works. Another risk is that I may become too dependent on AI and not practise solving problems by myself. A third risk is that AI can sometimes give incorrect or unsuitable code, so I need to check the suggestions and understand them before using them.
